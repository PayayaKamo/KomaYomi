# ライブラリ

ライブラリは、アプリの読み込みのたびに `raw/` フォルダをスキャンして構築されます。インポート手順もデータベースもありません。ディレクトリ構造が*そのまま*設定です。

## 必要なディレクトリ構成

```text
raw/
  <volume>/
    <language-dir>/
      <chapter>/
        001.jpg
        002.jpg
```

- **巻** は `raw/` 直下の任意のフォルダです。
- **話** は言語ディレクトリ内の任意のフォルダです。話は言語をまたいで統合されるため、ある言語に話フォルダがない場合もあります。
- **ページは並べ替えた位置で対応付けられ、ファイル名では対応付けられません。** 各言語のファイルは自然順（数字の連続は数値として比較）で並べ替えられ、インデックスで対応付けられます。`1.jpg`、`2.jpg`、`10.jpg` も正しく並びます。
- ページは一部の言語にしか存在しない場合があります。欠けている対応はページごとに報告されます。

## 言語ディレクトリ名

スキャナーはフォルダ名を正規化し（小文字化、スペースとアンダースコアをハイフンに）、別名と照合します:

| 言語 | 受け付けるディレクトリ名 |
| --- | --- |
| 日本語（`ja`） | `ja`, `jp`, `jpn`, `japanese`, `ja-jp`, `日`, `日本語`, `日文` |
| 中国語（`zh`） | `zh`, `zh-cn`, `zh-hans`, `zh-sg`, `cn`, `chs`, `zh-tw`, `zh-hk`, `zh-hant`, `cht`, `tw`, `hk`, `中`, `中文`, `繁中`, `简中` |
| 英語（`en`） | `en`, `en-us`, `en-gb`, `us`, `uk`, `eng`, `english`, `英`, `英文` |

フォルダ名が認識されない場合、巻は表示されますが警告が付きます。**巻の設定** を開いてディレクトリを言語に固定してください。選択内容は `data/library.json` に保存されます:

```json
{
  "volumes": {
    "点兔第14卷": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }
    }
  }
}
```

1つの巻は1つ、2つ、または3つの言語を持てます。比較リーダーは、現在のページに実際に存在する言語だけを提示します。

## 巻の追加と削除

- **巻を追加** は既存のフォルダをコピーせずに `raw/` にリンクします。Windows ではディレクトリリンクを使うため、大規模なライブラリが複製されません。リンクは通常のフォルダのように振る舞うので、注釈は書き込み可能なままです。
- **巻を削除** は `raw/` 以下のリンクだけを削除します。元のフォルダの画像はそのまま残ります。`data/pages/` に保存済みのページ注釈も保持されます。
- **巻の設定** は、ディスク上の名前を変えることなく、認識されないディレクトリを `ja` / `zh` / `en` に対応付けます。

## 表示される警告

ライブラリの警告は情報提供のためのもので、ページは開けます。

| 警告 | 意味 | 対処 |
| --- | --- | --- |
| *言語ディレクトリが認識されません* | どのサブフォルダも別名に一致しませんでした。 | 巻の設定で対応付けるか、名前を変更してください。 |
| *認識されないディレクトリ: …* | 言語フォルダの隣に余分なフォルダがあります。 | 対応付けるか、無視してください。 |
| *言語間でページ数が異なります* | 言語ごとにファイル数が異なります。 | 対応付けはインデックスによるので、欠けているページを追加するか、余分なページを削除してください。 |
| *この話の中で拡張子が混在しています* | 例: `.jpg` と `.png` が交互に並ぶ。 | 通常は無害です。サムネイルの一貫性が必要なら統一してください。 |
| *ファイル名がページ番号と一致しません* | ファイル名の先頭の番号が、並べ替えた位置と異なります。 | 欠落や余分なページを示している場合は、ファイル名を変更してください。 |

## ナビゲーションとショートカット

| 操作 | ショートカット |
| --- | --- |
| 前のページ / 次のページ | `[` / `]` |
| コマ分割ワークベンチ | `P` |
| 比較リーダー | `C` |
| サイドバーの表示切替 | `S` |
| ノートパネルの表示切替 | `N` |
| エクスポートダイアログを開く | `E` |
| ヘルプ | `?` |

URL ハッシュはディープリンク可能です: `#/<volume>/<chapter>/<page>/<panels|compare>`。特定のページとビューを共有したりブックマークしたりでき、アプリは読み込み時にそれを復元します。

## サムネイルとパフォーマンス

サムネイルはオンデマンドで生成され、`data/cache/thumbs/` にキャッシュされます。このフォルダを削除しても問題ありません。次回の訪問時に再構築されます。画像形式はファイルヘッダーから判別されるため、実際には JPEG である `.png` も正しく表示されます。

::: warning WebP のデコード
内蔵の検出器は JPEG と PNG をデコードします。WebP は表示できますが、コマ検出のためにピクセルデータをデコードしません。自動検出に頼る場合は JPEG/PNG を使ってください。
:::
