# ライブラリとインポート

ライブラリは、アプリを読み込むたびに `raw/` をスキャンして作り直されます。データベースも、スキャンをコピーするインポート手順もありません。**ディレクトリ構造が設定そのもの** です。

このページでは、ファイルの置き方、スキャナーが言語を対応付ける仕組み、別の場所にあるフォルダのリンク方法、そしてインポートの入口がどこへ続くのかを説明します。

## 解決する課題

漫画のスキャンは、`Vol.14/Japanese/ch01`、`点兔第14卷/ja/172`、`manga/zh-cn/172` のように、前の持ち主の気分でさまざまな形で届きます。名前も場所も変えずに、巻と話を一覧できる棚が1つほしい。各言語の1ページ目をきちんと対応付け、ファイルが欠けている場所を教えてほしい。それがこのライブラリです。

## ディレクトリ構成

```text
raw/
  <volume>/
    <language-dir>/
      <chapter>/
        001.jpg
        002.jpg
```

1つの `raw/` に複数の作品を並べ、それぞれの下に巻を置くこともできます。

```text
raw/
  <work>/
    <volume>/
      <language-dir>/
        <chapter>/
          001.jpg
```

- **巻** は既定では `raw/` 直下のフォルダです。複数の作品を並べた場合は、作品フォルダの下のフォルダが巻になり、作品名がシリーズとして表示されます（サイドバーでは「シリーズ · 巻」）。両方の配置を混在させられます。スキャナーは単層の巻ルールを先に試し、合わなければシリーズのルールに切り替わります。詳しくは[ディレクトリ規則](/ja/guide/folder-rules#複数の作品を並べたルート)を参照してください。
- **話** は言語ディレクトリ内の任意のフォルダです。話は言語をまたいで統合されるため、ある翻訳版では話フォルダがまるごと欠けていることもあります。
- **ページはファイル名ではなく、並べ替えた位置で対応付けられます。** 各言語のファイルを自然順（連続する数字を数値として比較）で並べ、そのインデックスで対応付けます。`1.jpg`、`2.jpg`、`10.jpg` も正しい順に並びます。

## 言語ディレクトリ名

スキャナーはフォルダ名を正規化し（小文字化、空白とアンダースコアをハイフンに変換）、別名と照合します。

| 言語 | 受け付けるディレクトリ名 |
| --- | --- |
| 日本語（`ja`） | `ja`, `jp`, `jpn`, `japanese`, `ja-jp`, `日`, `日本語`, `日文` |
| 中国語（`zh`） | `zh`, `zh-cn`, `zh-hans`, `zh-sg`, `cn`, `chs`, `zh-tw`, `zh-hk`, `zh-hant`, `cht`, `tw`, `hk`, `中`, `中文`, `繁中`, `简中` |
| 英語（`en`） | `en`, `en-us`, `en-gb`, `us`, `uk`, `eng`, `english`, `英`, `英文` |

フォルダ名を認識できない場合、巻は表示されますが警告が付きます。**巻の設定**（巻の行の歯車）を開き、ディレクトリを言語に割り当ててください。この選択は `data/library.json` に保存されます。

```json
{
  "volumes": {
    "ご注文はうさぎですか? 第14巻": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }
    }
  }
}
```

巻に持たせられる言語の数は、割り当てた分だけです。組み込みの3言語は、いわば常連の顔ぶれ。比較リーダーは、現在のページに実際に存在する言語だけを提示します。

## 巻の設定

巻の設定は、フォルダがきちんと名乗ってくれなかった巻のための修理場です。巻の行の歯車から開きます。

1. ダイアログには、その巻で検出された言語ごとのドロップダウンに加えて、**日本語**、**中文**、**英語**が既定で並びます。
2. それぞれの言語が入っているサブフォルダを選びます。**未使用 / 自動**のままなら自動認識に任せます。
3. **保存**を押すとライブラリが再走査され、巻の言語バッジが更新されます。
4. **ライブラリから削除**は `raw/` のリンクだけを消します。元のフォルダの画像と `data/pages/` の注釈は残ります。

1つのフォルダを割り当てられる言語は1つだけです。すでに使われたフォルダは他のドロップダウンから消えます。言語フォルダが1つも見つからない場合は、その旨と、巻に出ている警告の理由がダイアログに表示されます。

::: tip 注釈の前に割り当てを決める
コマとノートは巻・話ごとに保存されます。あとから割り当てを変えると、ページデータを見つけられなくなることがあります。割り当てを決め、数ページ開いて確認してから、コマの修正を始めてください。
:::

## 別の場所にあるフォルダの追加

**＋ マンガを追加** には2つのモードがあります。

| モード | 動作 |
| --- | --- |
| パスを空欄にする | `raw/` の下に空のフォルダを作成します。 |
| 既存のフォルダを選ぶ | 元のフォルダを指す **フォルダリンク** を `raw/` の下に作成します。画像はコピーされず、リンクは通常のフォルダと同じように動くので、注釈もそのまま読み書きできます。 |

任意: 巻に別の表示名を付けられます。フィールド下のヒントには、想定される構成 `language/chapter/page.jpg` が表示されます。

選択したフォルダ自体が作品やシリーズで、`作品/巻/言語/話/画像` のように巻が階層になっている場合、ツールは各巻を `raw/` 直下にリンクし、作品名を `data/library.json` の `series` に記録します。サイドバーには「シリーズ · 巻」と表示され、別々の作品にある同名の巻は統合されません（巻 ID に作品名の接頭辞が付きます）。

**ライブラリから削除**（巻の設定内）は `raw/` の下のリンクだけを削除します。元のフォルダの画像はそのまま残り、`data/pages/` に保存済みの注釈も保持されます。

通常のブラウザではフォルダ選択ダイアログを開けません。絶対パスを直接入力するか、デスクトップ版で **フォルダを選択…** をクリックしてください。

## ページと言語の役割

混同しやすい3つの「役割」があります。

| 役割 | 指定する場所 | 影響する範囲 |
| --- | --- | --- |
| **下地画像**（基準画像） | コマ分割ワークベンチのツールバー | どの言語の画像にコマを描くか。コマの矩形はそのページの全言語で共有されます。 |
| **比較言語** | 比較リーダーの言語チップ | 表示する言語とその順序。すべての言語を有効にする必要はありません。 |
| **優先言語** | PNG エクスポート | ページ全体と現在のコマの PNG は下地画像の言語を使い、3言語コラージュは選択した比較言語を使います。 |

コマとノートは言語ごとではなく、ページごとに1回だけ保存されます。位置合わせのオフセットは言語ごと、任意でコマごとに保存されます。

## 表示される警告

ライブラリの警告はちょっとした噂話で、エラーではありません。ページはちゃんと開きます。

| 警告 | 意味 | 対処 |
| --- | --- | --- |
| *言語ディレクトリが認識されません* | サブフォルダがどの別名にも一致しませんでした。 | 巻の設定で割り当てるか、名前を変更します。 |
| *未認識のディレクトリ：…* | 言語フォルダの隣に余分なフォルダがあります。 | 割り当てるか、無視します。 |
| *言語間でページ数が異なります* | 言語ごとにファイル数が違います。 | 対応付けはインデックス順です。欠けているページを追加するか削除します。 |
| *この話に混在した拡張子があります* | 例：`.jpg` と `.png` が交互にあります。 | 通常は無害です。サムネイルを揃えたいなら形式を統一してください。 |
| *ファイル名がページ番号と一致しません* | ファイル名先頭の数字が並び順と異なります。 | 欠落や余分なページを示す不一致なら、名前を変更します。 |

## 特殊なディレクトリ構成

既定の構成でほとんどのライブラリは扱えます。単層の `巻/言語/話` と、`作品/巻/言語/話/画像` のように複数の作品を並べたルートは、どちらもそのまま認識されます。言語が最後にある、言語フォルダが無い、話の階層が無い——そんな場合は**フォルダ検出の規則…**を開き、プレースホルダーでパスを記述してください。規則は順に試され、最初に一致したものが使われます。検出だけに影響し、ファイルの改名や移動は行いません。

構文、規則のフィールド、プレビューの手順は[フォルダ検出の規則](/ja/guide/folder-rules)にまとめてあります。

## インポート、交換、復元

サイドバーには4つの入口があり、それぞれ役割が違います。

| 入口 | 用途 |
| --- | --- |
| **マンガを追加** | 既存の画像フォルダをライブラリにリンクします。 |
| **プロジェクトファイル…** | `.mnproj` パッケージ（画像 + 注釈 + テンプレート + 言語設定）をエクスポートまたはインポートします。 |
| **交換ファイル…** | `.mntpl` レイアウトテンプレート、`.mnexp` エクスポートテンプレート、単一の `.mnpage.json` ページをやり取りします。 |
| **バックアップ / 復元** | `data/` フォルダを ZIP にするか、以前の ZIP を復元します。 |

インポートは最初に検証され、元のファイルは `data/backups/` にバックアップされます。ファイルの内容とバージョンの規則は [プロジェクトファイルと形式](/ja/guide/project-files) を参照してください。

::: tip インポートの順序
注釈を同じマシンに戻したいときは **バックアップ** を復元します。別のマシンへ移るときは **プロジェクト** をインポートします。レイアウト、エクスポートスタイル、1ページだけを共有したいときは **交換ファイル** を使います。
:::

## ナビゲーションとパフォーマンス

| 操作 | ショートカット |
| --- | --- |
| 前 / 次のページ | `[` / `]` |
| コマ分割ワークベンチ | `P` |
| 比較リーダー | `C` |
| サイドバーの表示切り替え | `S` |
| ノート欄の表示切り替え | `N` |
| エクスポートダイアログを開く | `E` |
| ヘルプ | `?` |

URL ハッシュはディープリンクに使えます：`#/<volume>/<chapter>/<page>/<panels|compare|original>`。比較リーダーでコマをダブルクリックすると詳細表示が開き、URL に `/panel/<コマ ID>` が付きます（例：`#/vol-01/01/3/compare/panel/p-2`）。再読み込みやリンク共有でも、同じページの同じコマに戻れます。

コマ詳細では:

- 有効な言語がすべて横に並び（スマートフォンとタブレットでは縦に積み重なります）、その下にこのコマのノートと注釈が続きます。
- ツールバー、ホイール、ピンチで 100%〜600% のズームができます。ズームとパンは拡大画像にだけ作用します。
- 中央の矢印で前 / 次のコマ、いちばん外側の矢印でページを移動します。詳細を開いている間、矢印キーはページではなくコマを切り替えます。
- `Esc`、閉じるボタン、ブラウザーの戻るで終了し、元のページとコマ位置に戻ります。他の人から共有されたリンクでは、履歴を増やさず URL を書き換えます。

サムネイルはオンデマンドで生成され、`data/cache/thumbs/` にキャッシュされます。このフォルダは削除しても問題なく、次回表示時に再生成されます。画像形式はファイルヘッダーから判定されるため、実際は JPEG の `.png` も正しく表示されます。

## よくある落とし穴

- **ファイル名を変えるとページ位置が変わります。** 対応付けは並べ替えたインデックス順です。ページを挿入すると、それ以降のページがすべてずれます。新しいページは末尾に追加するか、話全体の名前を一貫して変更してください。[画像の前処理と名前変更](/ja/guide/preprocess)を参照してください。
- **言語が1つ欠けていてもエラーではありません。** ページは開き、比較リーダーは欠けている言語のプレースホルダーを表示します。
- **フォルダリンクはコピーではありません。** 元のフォルダを移動または削除すると、ライブラリが壊れます。移動後はフォルダを追加し直してください。
- **WebP は表示できますが、検出用にデコードされません。** 自動分割に頼る場合は JPEG または PNG を使用してください（[コマ分割ワークベンチ](/ja/guide/panels) 参照）。
- **サイドバーが正解です。** 巻や話が見つからない場合は、まずフォルダ名の大文字小文字と言語の別名を確認してください。
- **言語ドロップダウンに目的のフォルダが出ない。** 巻の設定で別の言語に割り当て済みです。
