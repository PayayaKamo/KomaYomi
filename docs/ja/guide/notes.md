# ノート

ノートこそが、コマと位置合わせが存在する理由です。ノートはページ全体にも1つのコマにも属することができ、Markdown で書きます。

## スコープ

| スコープ | 使う場面 | 保存形式 |
| --- | --- | --- |
| **ページ** | ページ全体の所見、校正上の指摘、ページについての疑問。 | `scope: "page"`, `panelId: null` |
| **コマ** | 言い回し、トーン、翻訳の違い、特定の吹き出し。 | `scope: "panel"`, `panelId: "<panel id>"` |

ワークベンチでも比較リーダーでも、コマを選択すると次のノートがそのコマのスコープになります。何も選択していないときは、ノートはページのスコープになります。

## Markdown

エディタは見出し、太字／斜体／取り消し線、インラインコード、フェンス付きコード、リンク、番号付き／箇条書きリスト（ネストは1階層）、引用、表、水平線、強制改行に対応しています。

- **プレビュー** を切り替えると、Markdown が HTML エクスポートで表示されるのとまったく同じ形でレンダリングされます。
- `Ctrl+Enter` でノートを保存します。
- ノート内の生の HTML はエスケープされ、実行されることはありません。
- Markdown 対応より前に書かれたノートは保存されており、改行を保ったプレーンテキストとして表示されます。

## タグ

- タグを入力して `Enter` を押すと追加されます。
- タグはノート上の配列として保存されます。
- タグの使用状況はすべてのページから集計され、候補／フィルターとして表示されます。

## 出典

各ノートは出典を持てます:

- **URL** — リンクを貼り付けます。アプリはテキスト中の最初の URL を自動で検出し、ボタンでページタイトルを取得できます（5秒でタイムアウト）。取得がブロックされる場合は、タイトルを手動で入力してください。
- **自由記述** — 例: `ChatGPT conversation 2026-05-12`、書籍名、インタビュー名など。

出典はノート一覧でバッジ（ドメイン）として表示され、検索と「コンテキストをコピー」に含まれます。

## スクラッチパッド

スクラッチパッドは、どのページに属するかを決める前の考えを書くための場所です。

- 自由に書けます。内容はブラウザのローカルストレージに保持されます。
- 所属がわかったら、項目をページまたはコマのノートへ移します。
- ブラウザごとのものであり、プロジェクトパッケージには含まれません。

## 概要と検索

**概要 / 検索** タブはライブラリ全体のノートを集約します:

- ノート本文、タグ、出典に対する全文検索（300 ms のデバウンス）。
- 巻、話、タグ、出典でフィルター。
- タグまたは出典で集計。
- 結果には、一致したノート数とページ数が表示されます。
- 結果をクリックするとそのページへ移動し、該当する場合はコマを選択します。

## コンテキストをコピー

**コンテキストをコピー** は、巻、話、ページ、コマ番号、ノート本文、タグ、出典を含む、貼り付け可能なコンパクトなブロックを生成します。形式は次のプレースホルダーを持つテンプレートで制御されます:

```text
{volume} {chapter} {page} {panel} {notes} {text} {tags}
```

テンプレートは編集可能で、ブラウザごとに記憶されます。自己完結した質問を LLM に貼り付けるのに便利です。

## 保存場所

ノートは `data/pages/<volume>/<chapter>/<index>.json` のページ JSON 内にあります:

```json
{
  "id": "n1712345678901",
  "scope": "panel",
  "panelId": "p3",
  "text": "**原文**：……\n\n翻译语气偏正式。",
  "tags": ["语气", "待确认"],
  "source": { "title": "…", "url": "https://…" },
  "createdAt": "2026-05-12T10:00:00.000Z",
  "updatedAt": "2026-05-12T10:05:00.000Z"
}
```

つまり、ノートはページと一緒にバックアップ・エクスポートされ、任意のテキストエディタで編集できます。

::: warning 予定
ノートモデルには data URL として保存されるスクリーンショット用の `images` フィールドがあり、プロジェクトのインポーターはノート内の画像を数えます。ノートに画像を追加するアプリ内エディタは <Badge type="warning" text="予定" /> です。
:::
