# 画像の前処理と名前変更

KomaYomi は指定したフォルダの画像をその場で読み込みます。コピーも変換も改名もしません。だからこそ、巻を追加する前の数分の整理が、コマ検出・ページの対応づけ・比較リーディングの出来を決めます。少し面倒でも、同じページを3言語で3回直すよりは安上がりです。

## この工程で解決すること

自動分割はきれいなスキャン向けに調整されています。ページが傾いている、スキャナの黒枠が残っている、WebP が混ざっている、あるいはどれか一つの言語でページが 1 枚足りない—そうした状態でもライブラリは開けますが、対応づけ、位置合わせ、ノート、エクスポートという後工程すべてがその問題を引き継ぎます。一度整理しておけば、同じページを 3 言語で 3 回直す手間がなくなります。

## ファイルの扱われ方

| 動作 | 影響 |
| --- | --- |
| 指定したフォルダから直接読み込みます。 | 取り込みも複製もしません。編集は `data/` にだけ書き込まれます。 |
| ページは**並び順**で対応づけます。ファイル名ではありません。 | 改名すると順番が変わります。途中に 1 枚挿すと、以降のページがすべてずれます。 |
| 並びは自然順です。連続する数字は数値として比較します。 | ゼロ埋めがなくても `2.jpg` は `10.jpg` より前に来ます。 |
| WebP は表示できますが、コマ検出用にはデコードしません。 | **自動分割**を使うなら JPEG か PNG に変換してください。 |
| 1 枚の画像が 1 ページです。 | 見開きは、全言語で同じように分割しない限り 1 ファイルのままにしてください。 |

## 整理のチェックリスト

原本を残したいなら、コピーのほうで作業してください。どのツールを使うかより、次の順番のほうが重要です。

1. **回転と傾き補正。** 読み方向はページごとに保存されますが、横倒しのスキャンを比較リーディングで直すことはできません。
2. **スキャナの黒枠と見開きの影を切る。** ページ端がまっすぐだと、端に接するコマも検出されやすくなります。
3. **自動分割を使うなら WebP を JPEG / PNG に変換。** セリフが読める画質は保ってください。
4. **1 話 1 フォルダ。** 1 つのディレクトリに 2 話を混ぜないでください。話はコマテンプレート、位置合わせプリセット、エクスポートの単位です。
5. **本文でない画像を除く。** 表紙、奥付、カラーページ、他の版に存在しない特典画像などです。これらは以降のページをすべてずらします。
6. **見開きは分割しないか、全版で分割する。** 見開きは 1 ページとして数えます。日本語版だけ分割して中国語版を分割しないと、日本語の 12 ページ目が中国語の 12–13 ページ目になり、対応が崩れます。
7. **ファイル名は必要なら整える。** ゼロ埋め（`001.jpg`）は差分確認や目視に便利ですが、スキャナは並び順と自然順を見るので `1.jpg` でも `001.jpg` でも動きます。

## 話をまとめて改名する

アプリ内の一括改名・画像変換はまだありません—<Badge type="warning" text="予定" />。**前処理…** ダイアログでは巻や話の表示名を変えたり、ページ順の入れ替えや除外ができますが、書き込まれるのはライブラリ設定（`library.json`）だけです。ディスク上のファイル名はそのまま残ります。実際の改名にはファイルマネージャーかシェルを使ってください。Windows なら PowerShell で並べ替えてから連番にできます。

```powershell
# まずプレビュー。-WhatIf は予定の改名を表示するだけで、何も変更しません。
Get-ChildItem -File | Sort-Object Name | ForEach-Object -Begin { $i = 1 } -Process {
  $new = '{0:D3}{1}' -f $i, $_.Extension.ToLower()
  Rename-Item -LiteralPath $_.FullName -NewName $new -WhatIf
  $i++
}
```

プレビューが正しければ `-WhatIf` を外し、その話の言語フォルダごとに同じコマンドを実行します。改名が既存の注釈に影響しないのは、**ページ数と順番が変わらない場合だけ**です。ページデータはファイル名ではなく、話とページ番号で管理されています。

::: warning 改名で注釈が別ページに付くことがあります
改名でページ数や順番が変わると、`data/pages/<巻>/<話>/<番号>.json` は編集したページを指さなくなります。コマを直す前に改名を終えるか、終わったあとでバックアップから復元してください。
:::

## 注釈を始める前の確認

1. 巻を追加し、サイドバーで開きます。
2. 巻と話の行に出る警告を読みます。*言語間でページ数が違う* と *ファイル名がページ順と一致しない* は、整理ミスのサインです。
3. フォルダ構成が特殊なら、**フォルダ検出の規則…** を開き、プレビューで確認してから保存します。[フォルダ検出の規則](/ja/guide/folder-rules)を参照してください。
4. 最初、中央、最後のページを開き、同じコマに同じ絵が入っているか確かめます。ずれていれば、ページ数か見開きの扱いが間違っています。
5. ここまで確認してから**自動分割**を実行し、ノートを書き始めます。

## よくある落とし穴

- **1 つの言語だけ 1 ページ多い。** 表紙や奥付が余分なことが多いです。削除するか、他の言語にも同じページを足してください。
- **見開きが 1 版だけ分割されている。** 見開きはそのままにするか、全版を同じ位置で分割します。
- **WebP ページの自動分割がめちゃくちゃになる。** 形式を変換してください。検出は WebP をデコードしません。
- **改名したらノートが次のページに移った。** ページデータは番号で管理されています。注釈の前に改名するか、ページ履歴で確認してください。
- **ページは正常なのにサムネイルの形式が混在する。** サムネイルは拡張子ではなく中身に従います。実体が JPEG の `.png` も正しく表示されるので、見た目だけの問題です。
- **注釈のあとでフォルダを組み替えた。** 検出 ID が変わり、以前のページデータが見つかりません。フォルダ検出の規則は注釈の前に適用してください。
