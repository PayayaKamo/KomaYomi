# キーボードショートカット

すべてのキーとマウスジェスチャーを1ページにまとめました。テキストフィールドにフォーカスがある間は単キーのショートカットは無視されるため、ノート入力の途中で表示が切り替わることはありません。

## このページで解決すること

ショートカットはライブラリ、ワークベンチ、比較リーダー、ノートエディタに分散しています。各章を探し回る代わりに、操作を覚える間はこのページを手元に置くか、印刷してモニターの横に貼ってください。

## 全体

| キー | 動作 |
| --- | --- |
| `[` | 前のページ（話の境界を越えます）。 |
| `]` | 次のページ（話の境界を越えます）。 |
| `←` / `→` | 閲覧方向に沿って前 / 次のページへ。縦読みでは `↑` / `↓`。 |
| `P` | コマ分割ワークベンチに切り替え。 |
| `C` | 比較リーダーに切り替え。 |
| `O` | 原版ビューに切り替え。 |
| `S` | ライブラリサイドバーの表示 / 非表示。 |
| `N` | ノート列の表示 / 非表示。 |
| `E` | エクスポートダイアログを開く（ページを開いている場合）。 |
| `R` | 集中モードに入る / 出る。 |
| `Esc` | 集中モードを終了する（ダイアログが開いていないとき）。 |
| `?` | キーボードと操作のヘルプを開く。 |
| `Ctrl+Z` | 最後のコマの変更を元に戻す。 |
| `Ctrl+Shift+Z` | やり直す。 |
| `Ctrl+Y` | やり直す（代替）。 |

閲覧モードでは編集系のショートカット（`Ctrl+Z`、`Ctrl+Y`、保存、コマや注釈のキー）は無効です。ページ送りと表示の切り替えはそのまま使えます。

## 集中モード

`R` を押すか、上部バーの `⛶` をクリックすると入ります。上部バー、ステージのツールバー、コマのセクションレール、ステータスバーが畳まれ、ページが画面いっぱいに広がりますが、編集 / 閲覧モードは変わりません。`Esc`（ダイアログが開いていないとき）または `R` で戻り、タッチ端末では空白部分のダブルタップでも終了します。状態は記憶され、次回も維持されます。入ったときに終了方法を短く表示し、その後フェードアウトして絵を覆い続けることはありません。

## ファイル

| キー | 動作 |
| --- | --- |
| `Ctrl+O` | プロジェクトファイル（`.mnproj`）を開く。 |
| `Ctrl+S` | 現在のページを保存。 |
| `Ctrl+Shift+S` | プロジェクトファイルへ保存——ライブラリ全体を開いている `.mnproj` に書き戻します。 |

これらのファイルショートカットは、入力中でも動作し、デスクトップアプリと同じように振る舞います。読み取り専用モードや、プロジェクトがリンクされていない場合は、書き込まずに理由を表示して保存を拒否します。

**ファイル → 名前を付けて保存…** にショートカットはありません。保存先を毎回尋ねる操作なので、明示的に選ぶメニュー項目のままにしています。

## コマ分割ワークベンチ

| キー / ジェスチャー | 動作 |
| --- | --- |
| 枠をドラッグ | コマを移動。 |
| 角または辺のハンドルをドラッグ | 8方向にリサイズ。 |
| 空白をダブルクリック | 既定のコマを追加。 |
| 空白の上をドラッグ | コマを描く。 |
| `Shift` + ドラッグ | 新しいコマを正方形に固定。 |
| `Alt` + ドラッグ | 吸着を無効にする。 |
| `Ctrl` クリック / `Shift` クリック | 選択にコマを追加、または選択から外す。 |
| 矢印キー | 選択範囲をページの0.2%だけ移動。 |
| `Shift` + 矢印キー | 1%移動。 |
| `Delete` / `Backspace` | 選択したコマ（または選択した注釈）を削除。 |
| `Enter` | 保存（確認モード）。 |
| `Esc` | 変更を破棄（確認モード）。それ以外では注釈ツールを終了するか、マークの選択を解除。 |

注釈ツールバーには英字のショートカットはなく、マウスのみです。`Esc` は常に1段階戻ります。選択中の注釈 → 現在のツール → 未保存のページ、の順です。

## 比較リーダー

| キー / ジェスチャー | 動作 |
| --- | --- |
| `H` | すべてマスク（マスクの全体切り替えをオン）。 |
| `Shift+H` | すべて表示（マスクの全体切り替えをオフ）。 |
| ペインをドラッグ | その言語をパン。 |
| ペイン上でホイール | その言語を拡大縮小。 |
| `Alt` + ドラッグ / ホイール | 現在のコマだけにジェスチャーを適用。 |
| マスク中のペインをクリック | 一時的に表示。もう一度クリックするとマスク。 |

コマの移動には **前のコマ** / **次のコマ** ボタンを使います。`[` と `]` がすでにページ移動に使われているため、キーには割り当てられていません。

## ノートエディター

| キー | 動作 |
| --- | --- |
| `Ctrl+B` | 太字。 |
| `Ctrl+I` | 斜体。 |
| `Ctrl+K` | リンクを挿入。 |
| `Ctrl+Enter` | ノートを保存（または一時メモを保存）。 |
| タグ欄で `Enter` | タグを追加。 |
| `Tab` | エディター内でインデント。 |

## マウスのみの操作

一部のコントロールには、仕様上キーボードの代替がありません。

- ペインの区切りとコマ詳細ビューの分割線：ドラッグでサイズ変更、分割線はフォーカス時に方向キーでも移動できます。
- 比較リーダーの言語チップの並べ替え：チップをドラッグ。
- ズームボタン：コマのツールバーの `−` / `＋`。
- コマテンプレートと位置合わせプリセットの選択。
- 右クリックメニュー：注釈、比較ペイン、詳細ビューのコマ。ペインメニューには拡大表示、マスク、単一コマ PNG、コマ番号、リンクがあります。
- コマ詳細ビューで絵をドラッグして位置合わせする操作と **同期移動** スイッチ。
- 保存インジケーターをクリックして書き戻しパネルを開く操作。

## よくある落とし穴

- **ショートカットが文字を入力してしまう。** フォーカスが input、textarea、contenteditable 要素にあります。先にステージをクリックしてください。
- **`H` でマスクされない。** フォーカスがノートやツールバーのフィールドにあります。入力中は比較のショートカットは無視されます。
- **`E` が何もしない。** ページを開いていないため、エクスポートダイアログは使えません。
- **`Ctrl+Z` でノートが元に戻ってしまう。** テキストフィールド内ではブラウザ標準の元に戻すが働きます。ページ単位の元に戻す操作はステージ上でのみ機能します。
