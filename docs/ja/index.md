## なぜ KomaYomi なのか

漫画を外国語で読むとき、たいてい窓が三つ必要です。原作、翻訳、辞書。さらにノートアプリを開き、書きたい一文の位置はだいたいずれています。KomaYomi（格读）は、同じページの日本語・中国語・英語を一つの窓に並べ、まずコマに分け、Markdown ノートと注釈を絵のその場所に貼れるようにします。作業の単位はページではなくコマです。

ローカル Web アプリなので、ページ画像は `raw/` フォルダのまま、コマ、ノート、タグ、注釈は `data/` 以下のプレーンな JSON に保存されます。エクスポートしない限り、データがマシンの外に出ることはありません。スキャンは自分で用意してください。学習用のツールであり、漫画の配布サービスではありません。

作者ページ：[X · @payayakamo](https://x.com/payayakamo) · [note · @payayakamo](https://note.com/payayakamo)。どちらも作者個人のページで、製品サイトではありません。

## 3 手順ではじめる

1. **入れる、または走らせる**：[GitHub Releases](https://github.com/PayayaKamo/KomaYomi/releases) からビルドを入手。または `npm install && npm run dev` で `http://127.0.0.1:5173` を開く。
2. **ページを置く**：`raw/<巻>/<言語>/<話>/001.jpg` に置くか、「ファイル → ライブラリフォルダーを開く…」を使う。
3. **話を開く**：初回はコマが自動検出される（下書きとして扱う）。比較リーダーで読み、ノートを書き、書き出す。

インストール方法の詳細、初回のフォルダー構成、コマの修正は[インストールと起動](/ja/guide/installation)と[はじめに](/ja/guide/introduction)にあります。

## KomaYomi の 4 つのリポジトリ

このサイトが扱うのはデスクトップ完全版です。同じプロジェクトには他に 3 つの形態があります。

- [KomaYomi](https://github.com/PayayaKamo/KomaYomi) — デスクトップ完全版（Electron とローカルサーバー）。このドキュメントの対象です。
- [KomaYomi-online](https://github.com/PayayaKamo/KomaYomi-online) — ブラウザー専用版。`.mnproj` プロジェクトを開いて閲覧・注釈・エクスポートができ、サーバーは不要です。
- [KomaYomi-mobile](https://github.com/PayayaKamo/KomaYomi-mobile) — Android / iOS 向けの React Native アプリ。HarmonyOS NEXT は現在プレースホルダーのみです。
- [KomaYomi-docs](https://github.com/PayayaKamo/KomaYomi-docs) — このサイトのビルド成果物で、CI が push します。ドキュメントの編集はメインリポジトリで行ってください。

各形態は同じページ JSON と `.mnproj` 形式を共有しており、作業内容は形態間で移せます。
