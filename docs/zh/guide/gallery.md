# 图库

图库在每次应用加载时通过扫描 `raw/` 文件夹构建。没有导入步骤，也没有数据库：目录结构*就是*配置。

## 必需的目录结构

```text
raw/
  <volume>/
    <language-dir>/
      <chapter>/
        001.jpg
        002.jpg
```

- **卷**是 `raw/` 下的任意顶层文件夹。
- **章**是语言目录内的任意文件夹。各语言的章会取并集，因此某种语言可能缺少某个章文件夹。
- **页面按排序后的位置配对，而不是按文件名配对。** 每种语言的文件先做自然排序（连续数字按数值比较），然后按索引配对。`1.jpg`、`2.jpg`、`10.jpg` 的排序是正确的。
- 某一页可以只存在于部分语言中；缺失的配对会按页面报告出来。

## 语言目录名

扫描器会规范化文件夹名（转小写，空格和下划线转为连字符），再与别名匹配：

| 语言 | 接受的目录名 |
| --- | --- |
| 日语（`ja`） | `ja`, `jp`, `jpn`, `japanese`, `ja-jp`, `日`, `日本語`, `日文` |
| 中文（`zh`） | `zh`, `zh-cn`, `zh-hans`, `zh-sg`, `cn`, `chs`, `zh-tw`, `zh-hk`, `zh-hant`, `cht`, `tw`, `hk`, `中`, `中文`, `繁中`, `简中` |
| 英语（`en`） | `en`, `en-us`, `en-gb`, `us`, `uk`, `eng`, `english`, `英`, `英文` |

如果某个文件夹名无法识别，该卷仍会出现，但会带一条警告。打开**卷设置**把目录固定到某种语言；该选择保存在 `data/library.json` 中：

```json
{
  "volumes": {
    "点兔第14卷": {
      "dirs": { "ja": "raw-ja", "zh": "raw-zh" }
    }
  }
}
```

一个卷可以有一种、两种或三种语言。对照阅读只会提供当前页面实际存在的语言。

## 添加与移除卷

- **添加卷**会把已有文件夹链接进 `raw/`，而不是复制它。在 Windows 上使用目录链接，因此大型图库不会被复制一份。标注仍然可写，因为该链接的行为与普通文件夹一致。
- **移除卷**只会删除 `raw/` 下的链接；原文件夹中的图片不受影响。已经保存在 `data/pages/` 下的页面标注会保留。
- **卷设置**把无法识别的目录映射为 `ja` / `zh` / `en`，不会重命名磁盘上的任何内容。

## 你会看到的警告

图库警告只作提示；页面仍然可以打开。

| 警告 | 含义 | 解决方法 |
| --- | --- | --- |
| *未识别出语言目录* | 所有子文件夹都没有匹配到别名。 | 在卷设置中映射它们，或重命名。 |
| *无法识别的目录：…* | 语言文件夹旁边还有其他文件夹。 | 映射或忽略它们。 |
| *各语言页数不一致* | 各语言的文件数量不同。 | 按索引配对；补上或删掉缺少的那一页。 |
| *本章节扩展名不一致* | 例如 `.jpg` 与 `.png` 交替出现。 | 通常无害；如果在意缩略图一致，可统一格式。 |
| *文件名与页码不匹配* | 文件名开头的数字与其排序位置不一致。 | 如果该不一致说明缺页或多页，请重命名文件。 |

## 导航与快捷键

| 操作 | 快捷键 |
| --- | --- |
| 上一页 / 下一页 | `[` / `]` |
| 分格工作台 | `P` |
| 对照阅读 | `C` |
| 显示/隐藏侧边栏 | `S` |
| 显示/隐藏笔记面板 | `N` |
| 打开导出对话框 | `E` |
| 帮助 | `?` |

URL hash 支持深链接：`#/<volume>/<chapter>/<page>/<panels|compare>`。分享或收藏某个具体页面和视图；应用会在加载时恢复它。

## 缩略图与性能

缩略图按需生成并缓存到 `data/cache/thumbs/`。删除该文件夹是安全的；下次访问时会重新生成。图片格式从文件头识别，因此一个实际是 JPEG 的 `.png` 也能正确渲染。

::: warning WebP 解码
内置检测器解码 JPEG 和 PNG。WebP 可以显示，但其像素数据不会被解码用于分格检测；如果你依赖自动检测，请使用 JPEG/PNG。
:::
