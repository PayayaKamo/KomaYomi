# 笔记

笔记是分格与对齐存在的理由。一条笔记可以挂在整页，也可以挂在某一格；它用 Markdown 编写，能带标签、来源和附图。

## 它解决什么问题

像“这版翻译丢了敬语”这样的记录，一旦脱离它所指的对话框就失去意义。这里的笔记挂在页面或分格 id 上，因此能经受页面重排、模板变更和导出。第二个问题是检索：翻过五十页之后，你得把打了 `语气` 标签的笔记、或来自某一篇文章的笔记全部找出来。

## 页面笔记与格级笔记

| 范围 | 何时使用 | 存储为 |
| --- | --- | --- |
| **页面** | 整体观察、校对意见、关于某一页的疑问。 | `scope: "page"`、`panelId: null` |
| **分格** | 措辞、语气、某个对话框、翻译差异。 | `scope: "panel"`、`panelId: "<panel id>"` |

在工作台或对照阅读中选中一个分格，下一条笔记就会限定到该分格。没有选中时，笔记是页面级。编辑器占位文字会说明当前作用域：*记录这一格的原文……* 还是 *记录整页的观察……*。

## 笔记类型

一页或一格可以有很多条笔记，每条笔记都有类型。内置类型是 **背景知识**、**生词** 和 **吐槽**。一个项目启用多种语言时，每种启用的语言还会各有一个类型（例如 **日语** 或 **中文**）；禁用的语言不会出现。

笔记栏的顺序是 筛选 → 列表 → 编辑器。笔记按类型分组显示，**全部** 筛选会显示所有分组。点一个类型标签或 **添加笔记**，会以该类型开始一条新笔记，并把焦点移到列表下方的编辑器；草稿已经有内容时，点类型只会改这条草稿的类型。

自定义类型可以在类型行里新增、改名、换色和删除。它们存放在 `data/library.json` 的 `noteTypes` 中，因此跟着库走，而不是跟着某个浏览器配置。删掉某个类型后，仍在引用它的笔记会回落到背景知识。

在类型功能出现之前保存的笔记会迁移到背景知识。页面文档升到 `schemaVersion: 2`，原来的版本 1 文件会以 `<file>.v1.bak` 留在旁边（例如 `3.json.v1.bak`）。

格子详情页内嵌同一个编辑器，因此不用离开当前页就能写本格笔记。切格、翻页或返回之前，草稿会先落盘。

## 写一条笔记

<figure class="shot">
  <img src="/assets/screenshots/notes-editor.png" alt="笔记编辑器：Markdown 工具栏、编辑 / 分栏 / 预览切换、来源与标签输入框、暂存区">
  <figcaption>笔记编辑器：Markdown 工具栏、编辑 / 分栏 / 预览、来源和标签输入框，下面是暂存区。编辑器上方的范围提示说明下一条笔记属于整页还是某个分格。</figcaption>
</figure>

1. 在列表上方选一个类型标签，或点击 **添加笔记**。焦点会落到列表下方的编辑器；草稿已有内容时，点类型只改变这条草稿的类型。
2. 输入 Markdown。工具栏会插入常用语法：

| 按钮 | 插入 |
| --- | --- |
| **B** | 加粗（`Ctrl+B`） |
| *I* | 斜体（`Ctrl+I`） |
| • 列表 | 无序列表 |
| ❝ 引用 | 引用块 |
| `</>` | 行内代码 |
| ↗ 链接 | 链接（`Ctrl+K`） |
| H | 标题 |
| S | 删除线 |
| 1. | 有序列表 |
| — | 分割线 |

3. 选择模式：**编辑**、**分栏**（编辑器 + 预览）或 **预览**。
4. 按 `Ctrl+Enter` 或点击 **添加笔记**。

渲染输出会转义原始 HTML；HTML 永远不会被执行。在支持 Markdown 之前写的笔记仍按纯文本加换行渲染。

## 标签

- 输入标签后按 `Enter` 添加。
- 标签以数组形式存储在笔记上。
- 用量会在所有页面中汇总并作为建议提供，**筛选** 行可以按标签筛选当前页。

标签是构建个人分类体系最省力的方式：`语气`、`误译`、`文化`、`待确认`、`拟声词`。

## 附图

笔记可以带截图——适合记录参考页、版本对照，或那本你懒得扫的纸质书照片。

- 把图片**粘贴**到编辑器，或**拖放**到笔记表单。
- **添加图片** 打开文件选择器；每张附图都有缩略图和移除按钮。
- 小于 400 KB 的图片按原样存储（data URL）。更大的图片会缩放到最长边 1600 px，再以质量 0.85 重新编码为 WebP。
- 图片存放在页面 JSON 中笔记的 `images` 数组里，因此会随页面一起进入导出和工程文件。图片太多会让 JSON 变大；宁可用几张裁剪后的参考图，也不要用整页图。

## 来源

每条笔记都可以带一个来源：

- **URL** —— 粘贴链接。笔记正文中的第一个 URL 会自动填入。**抓标题** 会尝试读取页面标题，超时 5 秒；如果抓取被拦截，请手动输入标题。
- **自由文本** —— 例如 `ChatGPT 对话 2026-05-12`、书名或访谈名称。

来源显示在笔记下方，可用 **收起来源** 切换显示。

## 复制给大模型的上下文

**复制本页上下文** / **复制上下文** 会从当前页、选中的分格、笔记正文、标签和来源拼出一段提示词。

- 复制对话框有一个可编辑的 **模板前缀**。
- 支持的占位符：`{volume}`、`{chapter}`、`{page}`、`{panel}`、`{notes}`、`{text}`、`{tags}`。
- 对模板的修改会自动记住。
- **预览** 显示将要复制的确切内容；**复制** 把它放进剪贴板。

默认模板会要求模型解释语言点、语气和文化背景，并指出理解错误。按你偏好的讲解风格调整一次，之后每次复制都会沿用。

## 总览与搜索

**总览 / 搜索** 标签页在整个图库范围内工作，而不只是当前页：

- 搜索笔记正文、标签和来源。
- 按卷、话、页码、标签或来源筛选。
- 按话、标签或来源聚合结果。
- 结果上方会显示命中了多少条笔记、覆盖多少页。
- 点击结果跳转到该页；笔记如果是格级，还会跳到该分格。

**清除筛选** 重置当前查询。

## 暂存区

暂存区用来接住那些还没想好归属的想法——脑内的页边空白。

1. 在 **随手记暂存** 中输入，按 `Ctrl+Enter` 或点击 **记下**。
2. 之后用 **归到本页** 或 **归到本格** 把它变成正式笔记。

## 编辑与删除

每条已保存的笔记都有 **编辑**、**复制上下文**、**按标签筛选** 和删除操作。笔记上的 **渲染 / 源码** 开关在渲染后的 Markdown 和原始文本之间切换。删除分格会删除它的格级笔记，因此想与版式解耦的内容请用页面笔记。

编辑已有笔记时，内容会直接装进笔记栏顶部那一个编辑器，不会在笔记卡片里再展开一个 Markdown 编辑区：

- 编辑器上方出现 **正在编辑已有笔记** 的提示和 **取消** 按钮；取消会清空编辑器，原笔记保持不变。
- 提交按钮由 **添加笔记** 变成 **保存修改**。
- 编辑期间 **整页 / 分格** 作用域开关被锁定，避免保存时把笔记挪到另一个作用域。
- 被编辑的笔记卡片会高亮；删除这条正在编辑的笔记等同于取消编辑。

## 常见坑

- **笔记跑到了错误的作用域。** 检查编辑器上方那句话：它要么写出格号，要么写着*整页*。取消选中分格即可写页面笔记。
- **`Ctrl+Enter` 没反应。** 焦点必须在笔记编辑器内；在搜索框中不会触发该快捷键。
- **粘贴的截图太大。** 超过限制的图片会自动缩小，但整页截图仍然很重；先裁剪。
- **标签筛选隐藏了笔记。** **筛选** 行是按页生效的，与总览的筛选不是一回事。
- **文字看起来像代码。** 围栏代码块的首尾两行各要三个反引号。
