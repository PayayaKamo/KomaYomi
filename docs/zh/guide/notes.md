# 笔记

笔记是分格与对齐存在的理由。一条笔记可以属于整个页面，也可以属于某个分格，并且用 Markdown 编写。

## 范围

| 范围 | 何时使用 | 存储为 |
| --- | --- | --- |
| **页面** | 整体观察、校对意见、关于某一页的疑问。 | `scope: "page"`、`panelId: null` |
| **分格** | 措辞、语气、翻译差异、某一个对话框。 | `scope: "panel"`、`panelId: "<panel id>"` |

在工作台或对照阅读中选中一个分格，下一条笔记的范围就会限定到该分格。没有选中任何分格时，笔记是页面级的。

## Markdown

编辑器支持标题、粗体/斜体/删除线、行内代码、围栏代码块、链接、有序与无序列表（一层嵌套）、引用、表格、分隔线和硬换行。

- 切换 **预览** 可以按 HTML 导出中的最终效果渲染 Markdown。
- `Ctrl+Enter` 保存笔记。
- 笔记中的原始 HTML 会被转义，永远不会执行。
- 在支持 Markdown 之前写的笔记会被保留，并按纯文本加换行渲染。

## 标签

- 输入标签后按 `Enter` 添加。
- 标签以数组形式存储在笔记上。
- 标签使用情况会在所有页面中汇总，并作为建议/筛选条件展示。

## 来源

每条笔记都可以带一个来源：

- **URL** —— 粘贴链接。应用会自动识别文本中的第一个 URL；有一个按钮可以获取页面标题（5 秒超时）。如果获取被阻止，请手动输入标题。
- **自由文本** —— 例如 `ChatGPT conversation 2026-05-12`、书名或访谈名称。

来源在笔记列表中显示为徽章（域名），并会包含在搜索和“复制上下文”中。

## 速记板

速记板用于记录你还没决定归属哪一页的想法。

- 自由输入；条目保存在浏览器的本地存储中。
- 当你知道某个条目属于哪里时，把它移入页面或分格笔记。
- 它是按浏览器存储的，不属于项目包的一部分。

## 总览与搜索

**总览 / 搜索** 标签页会汇总整个图库中的笔记：

- 对笔记正文、标签和来源进行全文搜索（300 ms 防抖）。
- 按卷、章、标签和来源筛选。
- 按标签或按来源汇总。
- 结果显示匹配的笔记数和页面数。
- 点击某条结果会跳转到对应页面，并在适用时选中相应分格。

## 复制上下文

**复制上下文** 会生成一个紧凑、可直接粘贴的文本块，包含卷、章、页、分格编号、笔记正文、标签和来源。其格式由带以下占位符的模板控制：

```text
{volume} {chapter} {page} {panel} {notes} {text} {tags}
```

该模板可编辑，并按浏览器记忆。它便于把一条自包含的问题粘贴到 LLM 中。

## 存储

笔记位于页面 JSON 内，即 `data/pages/<volume>/<chapter>/<index>.json`：

```json
{
  "id": "n1712345678901",
  "scope": "panel",
  "panelId": "p3",
  "text": "**原文**：……\n\n翻译语气偏正式。",
  "tags": ["语气", "待确认"],
  "source": { "title": "…", "url": "https://…" },
  "createdAt": "2026-05-12T10:00:00.000Z",
  "updatedAt": "2026-05-12T10:05:00.000Z"
}
```

这意味着笔记会随页面一起被备份和导出，并且可以用任何文本编辑器编辑。
