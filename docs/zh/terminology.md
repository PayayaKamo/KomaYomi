# 术语表

本手册的三语版本统一使用下表中的术语。页面文字与界面标签不一致时，以界面标签为准；不确定时，查这张表。

这是给译者和跨语言读者共用的词典——分格 / panel / コマ 这种三头并立确实存在，而且是故意的。

界面标签按当前界面语言显示，因此按钮文字可能与正文用词略有差异。本表供翻译与跨语言阅读时统一引用。

## 避免使用的说法

| 避免 | 改用 | 原因 |
| --- | --- | --- |
| 图片（指扫描页） | 页面 | “图片”会与导出的 PNG 混淆。 |
| 裁剪框 | 分格 | 裁剪是导出动作；存下来的是分格矩形。 |
| 翻译 | 对照 | 应用只做版本对照，不做翻译。 |
| 同步（指标注） | 保存 | 标注是本地写入，不上传。 |
| 模板（单说） | 分格模板 / 布局模板 / 导出模板 | 三个不同对象共用“模板”一词。 |
