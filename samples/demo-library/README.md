# Demo library (original artwork)

This folder is a small, original sample volume used by the screenshots in the main README and in the documentation. Every page was drawn programmatically for this project — no third-party manga, scans or character designs are included.

- **Volume:** `Star Cafe`, chapter `01`, three pages
- **Languages:** `ja`, `zh`, `en` (the same three pages, localized dialogue)
- **Format:** 1000 × 1400 PNG, grayscale, 6–8 panels per page, with speech bubbles and a few sound effects
- **Size:** under 1 MB in total
- **License:** free to use, copy, modify and redistribute with this project (CC0 / public domain dedication)

The text is a short, ordinary scene: two people talk about stars, snow and coffee at a small café. It exists only to exercise the reader, panel detection, alignment and the export pipeline with content that is safe to publish.

## Try it

Copy the volume next to your own library and reload the app:

```text
raw/
  Star Cafe/
    ja/01/001.png …
    zh/01/001.png …
    en/01/001.png …
```

Or point a second copy of the app at a folder that contains this structure. Nothing else is required; the folder tree is the library.
